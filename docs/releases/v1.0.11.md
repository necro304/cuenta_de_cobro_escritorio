# CuentaCobro 1.0.11

## Novedades

- Nuevo instalador `.deb` para Ubuntu y otras distribuciones basadas en Debian.
- Se mantiene el formato `AppImage` para Linux y los instaladores existentes de Windows y macOS.
- Documentación de instalación en Ubuntu y datos del mantenedor para el paquete Debian.

## Desarrollo

- Incorporación de herramientas para agentes de desarrollo, revisión, diagnóstico, pruebas y diseño, con sus enlaces para Claude.
- Registro de la investigación sobre los formatos Linux publicados anteriormente.

## Análisis de impacto

Respecto a `v1.0.10`, los cambios se limitan al empaquetado, la documentación, las herramientas de desarrollo y el número de versión. No se modifican la interfaz, las reglas de cobro ni la persistencia; no se requieren migraciones de base de datos. Las herramientas para agentes no forman parte de los archivos de la aplicación configurados para empaquetado.

## Instalación en Ubuntu

Descarga `CuentaCobro-Linux-1.0.11.deb` desde los archivos de este release y ejecuta en la carpeta de descarga:

```bash
sudo apt install ./CuentaCobro-Linux-1.0.11.deb
```

**Cambios completos:** https://github.com/necro304/cuenta_de_cobro_escritorio/compare/v1.0.10...v1.0.11
