# CuentaCobro 2.0.0

CuentaCobro 2 es la misma aplicación que ya conoces, reconstruida sobre una tecnología nueva y más liviana. Tus clientes y cuentas de cobro se importan automáticamente la primera vez que la abres.

## Novedades

- **Nueva base: Tauri.** La app deja Electron y pasa a Tauri 2, con el backend en Rust. Los instaladores son mucho más livianos porque ya no incluyen un navegador completo: la app usa el que trae el sistema.
- **PDF nativo.** «Descargar PDF» genera la cuenta de cobro (Carta) y el informe de cliente (A4) con el motor de impresión del sistema, sin ventanas extra.
- **Importación automática de datos.** Al abrir la 2.0 por primera vez se copian tus datos de la 1.x y verás el aviso «Datos importados». La base de datos de la 1.x no se modifica ni se borra.
- **Zoom** con Ctrl/Cmd `+`, `-` y `0`, igual que en la 1.x.
- **Estado compartido con Pinia.** El perfil, los clientes, las cuentas bancarias, el tema y las actualizaciones se gestionan en un solo lugar: por ejemplo, al cambiar el tema también se actualizan al instante las gráficas.
- **Actualizaciones firmadas.** La app te pregunta antes de descargar una versión nueva y muestra el progreso.
- **Más plataformas.** Un solo `.dmg` para Mac con Apple Silicon e Intel, e instalador para Windows ARM64.
- **CLI para agentes.** El instalador trae `cuentacobro-cli`, con el que un agente de IA puede consultar y modificar tus datos desde la terminal, con las mismas reglas que la app. Para usarla desde cualquier terminal: **Configuración → CLI para agentes → Instalar en el PATH**. Primeros pasos en el [README](https://github.com/necro304/cuenta_de_cobro_escritorio#-cli-para-agentes).
- La ventana recuerda su tamaño y posición, y abrir la app por segunda vez enfoca la ventana que ya estaba abierta.

## Requisitos del sistema

- **macOS 12 (Monterey) o superior, con Safari 16.4 o superior.** macOS 13.3 y posteriores ya lo traen. En macOS 12 instala la última actualización de Safari desde Actualización de software: con un Safari anterior la app se ve sin estilos.
- **Windows 10 u 11 (x64 o ARM64).** Si falta Microsoft Edge WebView2, el instalador lo descarga (requiere internet la primera vez).
- **Linux: Ubuntu 22.04+ o Debian 12+ con las actualizaciones al día** (WebKitGTK 2.40 o superior).

## Instaladores

| Sistema                          | Archivo                             |
| -------------------------------- | ----------------------------------- |
| macOS (Apple Silicon e Intel)    | `CuentaCobro_2.0.0_universal.dmg`   |
| Windows x64                      | `CuentaCobro_2.0.0_x64-setup.exe`   |
| Windows ARM64                    | `CuentaCobro_2.0.0_arm64-setup.exe` |

Los archivos `.sig`, `.app.tar.gz` y `latest.json` los usa el actualizador automático: no hace falta descargarlos.

## Si vienes de la versión 1.x

**macOS: esta vez hay que instalar a mano.** La 1.x de macOS no puede actualizarse sola, así que no recibirás ningún aviso: descarga el `.dmg` y sigue los pasos de abajo. A partir de la 2.0, las versiones siguientes llegan solas.

- **Windows:** descarga `CuentaCobro_2.0.0_x64-setup.exe` (o `arm64`) y ejecútalo. El instalador retira la versión anterior y conserva tus datos. Si la 1.x estaba instalada «para todos los usuarios», desinstálala después desde Configuración › Aplicaciones (aparece como «CuentaCobro 1.0.x»). Si después de instalar sigues viendo la 1.x en Aplicaciones, desinstálala y vuelve a ejecutar el instalador 2.0 para recrear los accesos directos. SmartScreen avisará porque el instalador no tiene firma Authenticode: «Más información» › «Ejecutar de todas formas».
- **macOS:** abre `CuentaCobro_2.0.0_universal.dmg`, arrastra la app a Aplicaciones y acepta «Reemplazar». Después abre la Terminal y ejecuta:
  ```bash
  sudo xattr -cr /Applications/CuentaCobro.app
  ```
- **Ubuntu y Debian (.deb):** `sudo apt install ./CuentaCobro_2.0.0_amd64.deb` actualiza el paquete `cuenta-cobro` que ya tenías.
- **AppImage:** descarga el nuevo `.AppImage`, dale permiso con `chmod +x`, ábrelo y borra el anterior. En Ubuntu 24.04 o superior puede requerir `sudo apt install libfuse2t64`.
- **En todos los sistemas:** al abrir la 2.0 por primera vez, tus datos se importan automáticamente. No sigas usando la 1.x: lo que cambies allí ya no aparecerá en la 2.0.
- El tema (claro, oscuro o sistema) vuelve a “Sistema” la primera vez; elígelo de nuevo en Configuración.
- **Carpeta de datos en macOS.** Tus datos viven ahora en `~/Library/Application Support/com.cuentacobro.app`. En macOS, Finder muestra la carpeta `com.cuentacobro.app` como si fuera una aplicación (su nombre termina en `.app`). Para copiar tus datos usa Configuración → Crear respaldo. Si necesitas abrir la carpeta, haz clic derecho → «Mostrar contenido del paquete», o en Terminal: `open ~/Library/Application\ Support/com.cuentacobro.app`.

Las rutas de datos de cada sistema están en la sección «Dónde viven los datos» del [README](https://github.com/necro304/cuenta_de_cobro_escritorio#readme).

## Para desarrolladores

- Backend en Rust (`src-tauri/`) con SQLite mediante rusqlite. Las consultas, las reglas de la cuenta de cobro y sus mensajes de error se mantienen idénticos a los de la 1.x, con sus tests portados a `cargo test`.
- Frontend con Vue 3.5, Pinia, TypeScript 6.0, Vite 8 y Tailwind CSS 4 sin `tailwind.config.js`.
- Comandos nuevos: `npm run dev`, `npm run build:unsigned`, `npm run typecheck` y `npm run test:database` (`cargo test`).
- Las decisiones de la migración y las diferencias aceptadas respecto a la 1.x están en el [ADR 0001](https://github.com/necro304/cuenta_de_cobro_escritorio/blob/main/docs/adr/0001-migracion-a-tauri.md).
